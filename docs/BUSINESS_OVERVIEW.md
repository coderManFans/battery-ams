# 换电电池资产业务

## 参与方
电池资产所有方、换电运营商、仓库、换电站、维修服务商、设备平台和车辆用户可能属于不同主体。资产权属与实际保管位置分开表达。

## 生命周期
采购/接收 → 建档验收 → 仓库存储 → 出库/调拨 → 换电站投放 → 运行监测 → 异常隔离 → 检测维修 → 重新投放 → 退役处置。

## 关键概念
- SOC：剩余电量状态。
- SOH：电池健康状态估计。
- BMS：电池管理系统，采集电压、电流、温度等数据并执行相关保护。
- 资产状态、库存状态、健康状态、设备连接状态是不同维度。

## 维修闭环
异常发现 → 风险事件 → 冻结/隔离 → 创建工单 → 检测维修 → 验收 → 恢复可用或退役。跨服务通过事件和补偿协作。
